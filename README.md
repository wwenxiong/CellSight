# Wmap - 专业无线网优地图桌面系统

> **Wmap (Wireless Optimization Map)** 是一款面向无线网络规划与优化（网优）工程师的专业轻量级 GIS 地图桌面应用。  
> 秉持**“极简主义、极致克制、自解释布局”**的设计哲学，深度融合了基站扇区波瓣按方位角高精度渲染、免固定模板智能工参导入、`.wyp` 专属自包含工程文件管理、网优测距测角与 PCI 冲突智能排查工具箱，同时完整集成了面向突发事件的应急通信保障全流程闭环处置能力。

---

## 一、 核心功能特性

### 1. 基站扇区波瓣按方位角高精度渲染
* **拟真波瓣多边形**：基于球面上距离与方位角的精确几何解算，根据工参 `azimuth`（方位角）与水平波瓣开角（默认 65°，支持 30°~90° 实时滑动微调）在地图上矢量绘制精准扇形。
* **频段阶梯半径分层**：Sub-1G（700M/800M/900M，190m）、中频（1.8G/2.1G，140m）、高频（2.6G/3.5G/4.9G，95m）自动采用阶梯半径，彻底解决同物理站址多频段扇区重叠遮挡问题。
* **全向站/室分自适应**：无方位角、361° 或室分站点自动降级为全向同心圆，清晰区分宏站与室内分布系统。
* **多维着色模式切换**：支持顶栏一键循环切换：**按网络制式 (4G浅蓝 / 5G紫粉)** ➔ **按工作频段** ➔ **按 PCI 模 3**，存在活动告警时自动高亮显红。
* **精细化交互**：鼠标悬停高亮并展示微型气泡提示，单击弹出完整技术台账卡片（站名、小区名、CGI、PCI、频段、方位角、下倾角、经纬度）。

### 2. 零模板智能工参导入引擎
* **免固定模板**：兼容各大运营商及华为、中兴、爱立信、大唐等设备商原格式 Excel (`.xlsx`, `.xls`) 或 CSV 文件。
* **智能表头推断与模糊匹配**：后端内置 100+ 表头别名字典，自动识别并对齐小区名称、基站名称、经纬度、方位角、制式、频段、PCI、下倾角与挂高。
* **对齐确认抽屉**：导入时直观核对匹配结果，遇到特殊表头支持快速下拉微调，并支持勾选**“记住当前映射规则”**，后续秒级识别同类报表。
* **坐标系智能适配**：支持原表坐标系（WGS-84 大地坐标 / GCJ-02 火星坐标）一键切换与自动纠偏。

### 3. 专属工程文件 `.wyp` 体系
* **自包含工程包**：基于标准结构化容器，完整保存当前地图视窗（中心坐标、缩放层级、底图选择）、图层树、导入的全部工参扇区、标注图元与应急保障分析快照。
* **标准桌面工作流**：
  * **新建工程**：一键重置当前工作区；
  * **打开工程**：选择本地 `.wyp` 文件，秒级恢复全部图层与视角；
  * **保存工程 / 另存为**：支持快捷键 **`Ctrl + S`**，快速打包导出 `.wyp` 工程；
  * 顶栏常驻工程状态胶囊，实时显示工程名与未保存状态指示灯。

### 4. 网优高频实用工具箱
* **常驻全局地址/基站/坐标检索栏**：位于顶部工具栏正中央，支持全国地标 POI 联想、已载入工参快速检索、以及经纬度直达（按 `Enter` 地图平滑飞跃定位）。
* **网优专业测距测角标尺**：在地图上任意点击折线测量，顶点与中点**实时计算并给出两点间空间大圆距离与真北方位角 (0~360°)**，极大方便排查越区覆盖与天线对打。
* **PCI 冲突与混淆智能检测**：一键扫描当前视窗或工程范围内同频同 PCI、邻区同频同 PCI（默认 6km 门限），生成冲突清单并支持地图一键定位与红色警示虚线连线标记。
* **一键全图工参居中**：点击工具栏「全图」，根据当前所有基站扇区的外包围框自适应最佳视窗。

### 5. 应急通信保障专项闭环 (原功能完整继承)
* **空间精准定界**：支持中心点辐射圈选（500m~5km）与手绘任意闭合多边形圈选。
* **多源网管数据秒级关联**：支持华为、中兴 UME、爱立信告警与 15分钟/1小时 性能报表容错关联。
* **四级专家诊断规则库**：
  * **P0 紧急**：退服断站（SCTP/光模块故障或可用率<10%）；
  * **P1 高危**：高负荷拥塞（RRC>400 或 PRB>80%）或强干扰（RSSI>-100dBm）；
  * **P2 关注**：质差（掉线率>3%、切换成功率<90%、接通率<95%）；
  * **正常**：无告警且指标在基线内。
* **公文级双物料一键导出**：一键生成红头公文排版的《应急保障处置通报.docx》与条件格式高亮的《影响区域小区清单.xlsx》。

## 二、 目录结构说明

```
Wmap/
├── app/                        # 后端核心业务算法层
│   ├── coord_utils.py          # WGS-84 / GCJ-02 互转及大圆距离方位角解算
│   ├── smart_importer.py       # 零模板智能工参解析与表头别名推断引擎
│   ├── project_manager.py      # .wyp 专属工程文件打包、解包与生命周期管理
│   ├── pci_checker.py          # PCI 冲突与混淆排查算法
│   ├── param_loader.py         # LTE/NR 空间索引检索
│   ├── matcher.py              # 网管告警与性能数据模糊关联引擎
│   ├── diagnosis.py            # P0/P1/P2 四级专家智能诊断规则库
│   └── reporter.py             # Word (.docx) 与 Excel (.xlsx) 报告生成引擎
├── data/                       # 样例数据与持久化目录
│   ├── sample_alarms.csv       # 样例告警表
│   └── sample_kpi.csv          # 样例性能指标表
├── static/                     # 前端现代深色桌面静态资源
│   ├── css/                    # 界面样式表
│   └── js/
│       ├── wmap_sector.js      # 方位角扇区多边形几何与阶梯着色引擎
│       ├── wmap_tools.js       # 网优测距测角尺与工具函数
│       ├── wmap_project.js     # 工程文件生命周期前端控制器
│       └── app.js              # Leaflet GIS、图层管理器与全局状态机
├── main.py                     # FastAPI 后端服务主入口与 RESTful API
├── launcher.py                 # Windows 桌面独立视窗启动器
├── run.py                      # 便捷启动脚本
├── requirements.txt            # Python 依赖清单
└── README.md                   # 项目说明文档
```

## 三、 安装与启动指南

### 1. 环境依赖
* Windows 10 / 11
* Python 3.10+

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 运行程序
**原生启动（自动呼起浏览器视窗）：**
```bash
python run.py
```
或标准命令行模式：
```bash
python main.py
```
服务将在本地 `http://localhost:8080` 启动运行。
